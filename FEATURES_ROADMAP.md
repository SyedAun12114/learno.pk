# Learno Feature Roadmap

## 5 Features Added in This Patch

1. **Pomodoro Focus Timer** (/app/timer)
   A 25/5/15 minute focus timer with session counting and daily stats saved locally.

2. **Quick Notes** (/app/notes)
   Private notes saved in the browser. Create, edit, and delete notes instantly.

3. **Study Streak Badge**
   Tracks consecutive days of activity and shows a flame badge on dashboard.

4. **Global Search** (Ctrl+K)
   Search across tasks, study plans, skills, and opportunities from anywhere in the app.

5. **Streak API** (/api/streak)
   Backend endpoint that calculates consecutive active days from user activity logs.

## 25 Features for the Future

### Learning & Study
1. **Flashcard Generator** - AI generates flashcards from any topic or pasted notes
2. **Past Paper Analyzer** - Upload a past paper PDF, AI extracts key topics and patterns
3. **Subject-wise Performance Graphs** - Line charts showing test score trends per subject
4. **Study Group Rooms** - Shared study sessions with a common task board
5. **Spaced Repetition System** - AI schedules review sessions based on forgetting curves
6. **Syllabus Upload** - Upload your course syllabus, Learno builds the study plan automatically
7. **Voice Study Mode** - Text-to-speech reads study notes aloud for hands-free review
8. **Concept Map Builder** - Visual mind maps generated from study topics

### Career & Skills
9. **CV Builder** - AI generates a professional CV from the student profile and completed skills
10. **Cover Letter Generator** - AI writes a tailored cover letter for any saved opportunity
11. **Mock Interview Simulator** - AI conducts text-based mock interviews for selected roles
12. **Verified Skill Passport** - Skill completion certificates that can be shared publicly
13. **Portfolio Showcase Page** - Public profile page showing skills, test scores, and achievements
14. **Freelance Proposal Generator** - AI writes winning proposals for freelance opportunities
15. **GitHub Integration** - Link GitHub profile, show real project activity on the profile

### Productivity
16. **Calendar View** - Monthly calendar showing exams, deadlines, and study sessions
17. **Weekly Review Report** - Auto-generated weekly summary of progress sent by email
18. **Task Templates** - Reusable task templates for common study workflows
19. **Habit Tracker** - Track daily learning habits like reading 30 minutes or practicing coding
20. **Offline Mode** - View tasks and notes without internet connection

### Gamification
21. **XP and Levels** - Earn experience points for completing tasks, tests, and skill steps
22. **Achievement Badges** - Unlock badges for milestones like first test, 7-day streak, etc.
23. **Daily Challenges** - AI generates a new learning challenge every morning
24. **Leaderboard** - Optional anonymous leaderboard comparing weekly study hours

### Platform
25. **Dark Mode** - Full dark theme using the existing color system
